# Звіти до лабораторних робіт №1–6

## №1. Текстовий інтерфейс Jexer

**Мета.** Створити багатовіконний текстовий інтерфейс для перегляду даних клієнта банку.

**Хід роботи.** У класі `TUIdemo` підключено Jexer, створено головне меню, вікно клієнта та рядок стану. Дані з `test.dat` завантажуються до моделі банку. Обробник Show перевіряє номер клієнта і показує його ім’я, тип першого рахунку та залишок. У меню File можна відкрити ще одне вікно з даними клієнта. У меню Help доступна інформація про програму.

**Контрольний приклад.** Ідентифікатор 0 відповідає Jane Simms. Перший рахунок є ощадним і містить $500.00. Для номера 9 має з’явитися повідомлення про помилку.

**Висновок.** Jexer дає змогу реалізувати керування вікнами та діалогами в текстовому інтерфейсі. [Умова №1](https://github.com/liketaurus/TUI-Labs/blob/master/Lab%201%20-TUI/Lab%201.md)

## №2. Командний інтерфейс JLine 3

**Мета.** Побудувати CLI у вигляді циклу читання команд та показу результату.

**Хід роботи.** `CLIdemo` використовує JLine 3 для рядка `bank>`, доповнення команд клавішею Tab та історії вводу. Команда `customers` показує всі доступні ідентифікатори, `customer <номер>` показує рахунки вибраного клієнта, а `report` формує звіт за всіма клієнтами. Перед обробкою команд програма читає `test.dat`.

**Контрольний приклад.** `customer 2` має показати Tim Soley та два рахунки з балансами $1500.00 і $200.00. `customer 10` має показати помилку та повернути запрошення `bank>`.

**Висновок.** Цикл команд дає змогу виконувати кілька запитів за один сеанс. [Умова №2](https://github.com/liketaurus/TUI-Labs/blob/master/Lab%202%20-%20CLI/Lab%202.md)

## №3. Графічний інтерфейс Swing

**Мета.** Створити вікно, у якому можна вибирати клієнтів і переглядати інформацію про рахунки.

**Хід роботи.** У `SWINGdemo` компонент JComboBox містить клієнтів із `test.dat`. Вибір клієнта або натискання Show виводить усі його рахунки в JTextArea. Кнопка Report показує зведений звіт у тій самій області.

**Контрольний приклад.** Для Owen Bryant має бути показано поточний рахунок з балансом $200.00. Звіт має містити чотирьох клієнтів і шість рахунків.

**Висновок.** Обробники подій пов’язують вибір користувача з відображенням даних банку. [Умова №3](https://github.com/liketaurus/TUI-Labs/blob/master/Lab%203%20-%20SWING/Lab%203.md)

## №4. Форма NetBeans Matisse

**Мета.** Побудувати Swing-форму зі списком клієнтів, кнопками та областю результату.

**Хід роботи.** Файли `MatisseDemo.form` та `MatisseDemo.java` містять опис форми та її поведінку. Кнопка Show виводить усі рахунки вибраного клієнта, Report — зведений звіт, About — інформаційний діалог. Зміна розмірів вікна вимкнена.

**Контрольний приклад.** Вибрати Jane Simms і натиснути Show. В області результату мають відобразитися ощадний рахунок $500.00 та поточний $200.00. Далі натиснути Report і About.

**Висновок.** Форма описує компоненти та їх розміщення, Java-методи відповідають за дії кнопок. [Умова №4](https://github.com/liketaurus/TUI-Labs/blob/master/Lab%204%20-%20Matisse/Lab%204.md)

## №5. Графічний інтерфейс JavaFX

**Мета.** Побудувати JavaFX-застосунок для перегляду клієнтів та їхніх рахунків.

**Хід роботи.** Клас `FXDemo` створює Stage, Scene, список ComboBox та кнопки Show, Report і About. Список формується з `test.dat`. За Show відображаються всі рахунки вибраного клієнта, за Report — звіт за банком, за About — діалог із назвою застосунку.

**Контрольний приклад.** Вибрати Tim Soley і натиснути Show. Мають з’явитися два рахунки на $1500.00 і $200.00. Після Report у звіті мають бути всі чотири клієнти.

**Висновок.** JavaFX дає змогу створити дерево елементів керування в Java та прив’язати кнопки до обробників подій. [Умова №5](https://github.com/ppc-ntu-khpi/GUI-Lab3-Starter/blob/master/Lab%205%20-%20JavaFX/Lab%205.md)

## №6. JavaFX Scene Builder (Monet)

**Мета.** Описати графічний інтерфейс у FXML та реалізувати поведінку в контролері.

**Хід роботи.** Файл `MonetDemo.fxml` описує розміщення списку, кнопок і текстової області. `MonetDemo` завантажує його через FXMLLoader. `MonetController` читає дані та реалізує дії Show, Report і About.

**Контрольний приклад.** Після вибору Maria Soley кнопка Show має показати ощадний рахунок із балансом $150.00. Report має показати загальний звіт, а About — діалог.

**Висновок.** FXML дає змогу редагувати макет у Scene Builder і тримати логіку в окремому класі. [Умова №6](https://github.com/liketaurus/TUI-Labs/blob/master/Lab%206%20-%20Monet/Lab%206.md)
